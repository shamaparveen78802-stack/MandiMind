
# 🚀 MandiMind - Ek Saath Kharido, Zyada Kamao

MandiMind is an AI-powered collective procurement platform solving real problems for India's 10M+ street vendors.

### The Problem
- Street vendors buy in small quantities, missing wholesale benefits.
- No idea about future demand = stock-outs or heavy wastage.

### Our Solution
1.  **AI Demand Forecasting:** Predicts what will sell tomorrow using past sales, weather, and local trends.
2.  **Smart Pooling:** Combines demand of nearby vendors (e.g., 10 vendors need 100kg tomatoes).
3.  **Bulk Ordering:** Places one collective bulk order to get lower wholesale price, better availability & less wastage.

### Tech Stack
- Frontend: React Native / Next.js
- Backend: Node.js, Firebase
- AI/ML: Python, Prophet, Scikit-learn
- Maps: Google Maps Clustering API
